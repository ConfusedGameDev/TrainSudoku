Units, once and for all

BoardLayout works in cells. Unity scales the board's root so one unit is six centimetres. Do the same thing in Unreal with one twist: inside the board, one cell is 100 local units. Kit art authored one metre long then fits a cell with no per-mesh scaling, and the board root's scale turns that into centimetres in the room.

From a cell to centimetres

This is the only place the axis swap is written. If you find yourself swapping X and Y anywhere else, something has bypassed ToLocal.

Unreal concepts

Building an actor from components at runtime

Components declared in the constructor with CreateDefaultSubobject exist on every instance and show in the editor. Components made later, such as one per track piece, are created with NewObject, attached, and registered. An unregistered component does not render or collide.

Instanced static meshes

An 8×8 board has 64 identical slabs. One UInstancedStaticMeshComponent draws all of them in a single draw call. Each instance has a transform and can carry a few floats of per-instance custom data that the material reads. That is how one component draws slabs in two shades and highlights one of them.

Materials

A material is a shader graph. A material instance is that graph with different parameter values, with no recompile. A dynamic material instance is created in code and changed at runtime: the line colour, the ghost's tint. A material parameter collection is a set of global parameters every material can read. The paused-board dimming is one scalar in a collection, set once, where Unity walks every renderer.

Colour space

FColor is 8-bit sRGB, like Unity's Color32. FLinearColor is linear float, which is what materials want. Converting with FLinearColor(FColor) applies the sRGB curve. Constructing an FLinearColor directly from 0-to-1 sRGB numbers does not, and gives washed-out colours.

Steps

  1. Port BoardLayout. Keep it in cells and in its own frame; a small struct replaces the tuple. Do not convert to Unreal axes inside it. TrackCurve, TrackPath and BoardPick all share this frame, and their tests are written in it.

  2. Port the palette. Same names, same hex values.

  3. Make the materials in the editor. This part is not code.

    • MPC_Tsugi: a Material Parameter Collection with one scalar, Dim, default 1.
    • M_TsugiFlat: a default-lit opaque material. Base colour is a vector parameter Colour multiplied by the collection's Dim. Roughness about 0.8.
    • M_TsugiTile: the same, but base colour comes from a PerInstanceCustomData node's three floats, so each slab instance carries its own colour.
    • M_TsugiText: an unlit material for the clue numerals, with a Colour parameter and no dimming. The numbers must still read on a paused board.

    Assign them to the board in a Blueprint subclass, BP_TsugiBoard. C++ declares the slots; the Blueprint fills them. That is the division this course uses everywhere.

  4. Declare the actor.

    Name the file TsugiBoardActor.h so it does not collide with TsugiBoard.h in TsugiCore. Every map and array that holds components is a UPROPERTY; the plain-data map beside it is not.

  5. Load a level. The near edge of the board sits on the root's origin, so a bigger board grows away from the player and the edge they stand at never moves between levels.

    TileHeight is 0.1 and TileInset is 0.04, as in the C#. HighlightCell is then three more SetCustomDataValue calls on one instance.

  6. Draw placeholder track. Until lesson 8 bends real rails, draw each piece as two bars from the cell centre to the midpoints of its two sides. It uses Tsugi::Connections and FTsugiBoardLayout::Step, and it makes a wrong axis swap obvious at a glance: an NE piece must point away from you and to your right.

  7. Keep the display in step: Sync and Validate. Sync compares what is shown with the board, removes what changed and spawns what is new. Validate runs the win checker and dresses the clues: default ink, the line colour once a clue is met exactly, Stop red when a line holds more pieces than its clue.

  8. Connect it to the flow. In BeginPlay, find the subsystem and listen for OnLevelStarted. Load the level it names, with its line's colour. Add two console commands, Tsugi.Place x y KEY and Tsugi.Erase x y, that call TryPlace and TryErase on the board and then Sync(true).

    Place one BP_TsugiBoard in L_Tsugi at about (45, 0, 95) with its BoardRoot scale at 0.06. It will move into the room in lesson 10.

  9. Import the kit art you need. Copy these from the Unity project into Content/Art/Kit by importing the FBX files: spline-track.fbx, spline-segment.fbx, train-connector.fbx, and from Yamanote/ the two E235 cars, with their texture. For each mesh, open it in the Static Mesh Editor and write down its size and which axis runs along the track. Lesson 8 needs both numbers.

    Measure, do not assumeHow an FBX's axes and units arrive in Unreal depends on what the file declares and on the import options. This course cannot tell you the result for these files. Aim for: track running along local +X, 100 units long. Use the import rotation and uniform scale to get there, then confirm in the mesh editor.

Your port

  • FTsugiBoardLayout and its six tests.
  • BuildTunnels: for now a dark block at each TunnelCenter, with an S or E above it. The kit connector replaces it later.
  • BuildClues: a pole and a UTextRenderComponent at each ColumnClueAnchor and RowClueAnchor. In Tick, yaw each sign to face the camera, as Unity's LateUpdate does, so the numbers read from any side of the table.
  • Validate, including bHasOverfullLine, which the tutorial reads in lesson 15.
  • SetDimmed: set Dim in the parameter collection to 0.4 or 1 with UKismetMaterialLibrary::SetScalarParameterValue.
  • Spawn with a scale-in when bAnimate is set. PieceView.cs has the numbers: 220 ms, overshooting to 1.15. Lesson 13 covers ways to animate; for now a simple interpolation in Tick is fine.

Acceptance checks

  • Tsugi.Core.BoardLayout tests pass.
  • In the editor, Tsugi.Network, Tsugi.Line 0, Tsugi.Start 0 shows Ashgate with its fixed pieces.
  • Row 0 is the far row, and the row clues stand on the right-hand side. Compare with a screenshot or the Unity build.
  • An NE piece points away from me and to my right.
  • Placing a piece that completes a line turns that clue the line's colour; one piece too many turns it red.
  • The slabs are one draw call. Check with stat scenerendering or the GPU visualiser.
  • On the headset a cell measures six centimetres against a ruler.
  • Starting a 7×7 or 8×8 level keeps the near edge where it was.

Pitfalls

  • Forgetting RegisterComponent. The component exists, shows in the debugger, and draws nothing.
  • Mobility. Anything you move or create at runtime must be Movable. Attaching a movable component to a static parent logs a warning and refuses.
  • Text render fonts. UTextRenderComponent uses an offline font asset with a fixed set of glyphs. Digits are fine. Japanese on the platform decals needs a font asset that contains those glyphs, exactly the trap the Unity project documents for its world-space text.
  • Scale and collision. The board root is scaled to 0.06. Collision shapes scale with it, which is what you want, but anything you size in centimetres must be divided by that scale first.
  • A cached mesh destroyed by teardown. One Unity build freed the cached slab mesh on Clear, and every board after the first drew without slabs. In Unreal the slab mesh is an asset and the instances are cleared, not the mesh. Keep it that way.

Knowledge check

Why is one cell 100 local units with a root scale of 0.06, instead of 6 local units with a root scale of 1?

  • Unreal cannot render objects smaller than 10 units.
  • Art authored a metre long fits a cell unscaled, and changing the cell size is one number on the root.
  • Physics requires it.

The two-hand handle scales the board from 4 to 9 cm per cell by changing only the root's scale. Nothing inside the board knows about centimetres.

Unity dims a paused board by walking every renderer and setting a property block. What replaces that in Unreal?

  • Walking every component and creating a dynamic material instance for each.
  • One scalar in a material parameter collection that the board's materials multiply by.
  • A post-process volume.

A post-process effect would dim the passthrough view of the room as well. The collection touches only materials that read it.

FLinearColor(0.957f, 0.961f, 0.949f) is meant to be the Paper colour #F4F5F2. What is wrong?

  • Nothing.
  • Those are sRGB values placed in a linear colour without conversion, so the result is too bright.
  • FLinearColor takes integers.

Write the hex as an FColor and convert with FLinearColor(FColor), which applies the curve.
